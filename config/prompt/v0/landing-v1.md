# Format: landing page

- occasion_key: the key given in the task, exactly.
- title: the page heading. No token.
- intro: the occasion as a scene, in one short paragraph. It may use any pick's token, each at most once.
- sections: exactly one for each pick, in the order that reads best. Each has its slot and a caption.
- A caption sits under its pick's image and title, so it belongs to that pick alone. It carries no token and describes only that pick.
- Reader-visible prose is the intro plus all captions. Rendered titles above the captions do not count, but a token in the intro does.
